## What is Idlefy?

Cloud VMs run 24/7 even when no one is using them. Idlefy turns that around: developers **lease** a VM for the time they actually need it (30 min, 1 h, 8 h, or custom), and the platform notifies them before the lease expires. The human always decides — no surprise shutdowns.

Works with **AWS** and **Google Cloud Platform**, controlled from the web, **Telegram**, or **Slack**.

## Why teams use it

- 💰 **Cut idle spend** — pay only for the hours VMs are actually used
- 👁️ **Full visibility** — who is using what, how much it costs, per team
- 🤖 **CI/CD ready** — HTTP triggers from GitHub Actions, GitLab CI, and similar
- 🔔 **Stay in control** — expiry reminders in Telegram, Slack, and the browser
